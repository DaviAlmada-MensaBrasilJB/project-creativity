About the Project

Project creativity is a open source project focused on creating tools to improve performance, customization and user control of the hardware for better user experience.

What it does

Project Creativity's focus is create applications(aka Apps) for:

  • 🎨Customization
  • 🚀Better Performance
  • ⚙️Better control over hardware
  • 🎮Access to more resources(games, apps etc.)
